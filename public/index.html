Documentation API

Référence complète pour connecter Shopify à votre API

GET

/api

Retourne la liste des avis avec filtrage, tri et pagination.

Paramètres query

ParamètreTypeDescription
productstringFiltre par product_handle ou product_id
ratingnumberNote minimum (1-5)
searchstringRecherche texte (auteur, titre, corps)
sortstringChamp de tri : date, rating, author
orderstringasc ou desc (défaut)
limitnumberNombre max de résultats
offsetnumberDécalage pour pagination

Exemple

/api?product=serum-vitamine-c&rating=4&limit=10

Réponse

GUIDE

Intégration Shopify

Comment connecter cette API à votre section Liquid.

  1. Copiez le fichier section-premium-reviews.liquid dans sections/ de votre thème Shopify.
  2. Dans le Customizer, ajoutez la section "✨ Premium Reviews".
  3. Collez l'URL de votre API dans le champ "URL de l'API Vercel" :
    Chargement…
  4. Configurez les options visuelles (Glassmorphism, couleurs, Swiper…).
  5. Publiez ! Les avis apparaîtront automatiquement. ✅
CSV

Format du fichier CSV

Structure des colonnes dans data/reviews.csv

review_id,product_handle,product_id,author,email,rating,title,body,image_url,video_url,verified,date,country
ColonneRequisDescription
review_id✅ID unique de l'avis
product_handle✅Handle URL du produit Shopify
product_id—ID numérique du produit
author✅Nom de l'auteur
email—Email (non affiché publiquement)
rating✅Note de 1 à 5
title✅Titre de l'avis
body✅Texte de l'avis
image_url—URL image (400x400 recommandé)
video_url—URL vidéo (mp4)
verified—true / false
date✅Format YYYY-MM-DD
country—Code pays (FR, BE, CH…)

Mise à jour des avis

1. Modifiez data/reviews.csv
2. git add . && git commit -m "maj avis"
3. git push
→ Vercel redéploie automatiquement (~30s)
